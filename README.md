# PRIDE ONE — сайт школы брейкинга

Многостраничный сайт школы брейкинга PRIDE ONE: главная, о школе, филиалы и страницы каждого филиала, расписание, цены, жизнь клуба, запись на пробное занятие.

Сайт: https://goldlexx.github.io/

## Технологии
React 19 и Vite 6, без внешних UI-библиотек. Собственный маршрутизатор на History API. Каждая страница пререндерится в готовый HTML (`scripts/prerender.mjs`), поэтому сайт работает на любом статическом хостинге. Шрифты Inter и Oswald подключены локально (`public/fonts/`).

## Запуск
Нужен Node.js 24 (версия указана в `.nvmrc`).

```bash
npm ci
npm run dev        # разработка, http://localhost:5173
npm run build      # клиент + SSR + пререндер всех страниц в dist/
npm run preview    # просмотр dist/, http://localhost:4173
```

С адресом сайта сборка добавляет абсолютные canonical, og:url, og:image и `sitemap.xml`:

```bash
VITE_SITE_URL=https://goldlexx.github.io/ npm run build
```

## Режим публикации
Переключатель — `CONTENT_PREVIEW_MODE` в `src/data/preview.js`. В этом репозитории стоит `false` — публичный режим: на сайте только подтверждённые материалы, примеры заполнения и заглушки скрыты, пустые разделы не выводятся. Значение `true` включает демонстрационный режим с примерами заполнения карточек, его не публикуют.

У каждой записи в данных есть статус: `confirmed` — видна всегда; `slot` — пример заполнения или пустое место, видно только в демонстрационном режиме; `hidden: true` скрывает запись в любом режиме.

## Где редактировать данные
Весь контент лежит в `src/data/`, компоненты трогать не нужно.

| Файл | Что там |
|---|---|
| `branches.js` | филиалы, адреса, расписание (единый источник для всех страниц) |
| `prices.js` | цены |
| `coaches.js` | тренеры |
| `reviews.js` | отзывы |
| `club.js` | видео и события клуба |
| `achievements.js` | достижения |
| `gallery.js` | фотогалерея |
| `content.js` | тексты: философия, тренировка, ценности, история |
| `site.js` | контакты, меню, видео-знакомство |
| `../routes.js` | карта сайта, заголовки и описания страниц |

Формат записей описан в комментариях в начале каждого файла.

## Фотографии
Сейчас на сайте демонстрационные AI-фотографии (вымышленные люди) из `public/img/ai/`. Настоящие фотографии детей публикуются только при наличии письменного согласия родителей.

Новое фото можно добавить простой записью `{ src: '/img/имя.jpg', alt: 'что на фото', width: 1600, height: 1200 }` — с размерами место под фото известно заранее и страница не «прыгает» при загрузке. Фото в шапках страниц (`PageHero`) кадрируется по точке `pos`, заданной на странице: широкие кадры показываются целиком, более узкие заполняют область фото, а `pos` удерживает в кадре лица и главное действие.

## Публикация
Сайт публикуется на GitHub Pages через GitHub Actions (`.github/workflows/deploy.yml`): при каждом push в ветку `main` выполняются `npm ci` и `npm run build` с `VITE_SITE_URL=https://goldlexx.github.io/`, и содержимое `dist/` выкладывается на Pages. В настройках репозитория: Settings → Pages → Build and deployment → Source: GitHub Actions.

Сайт рассчитан на корень домена: пути `/img`, `/fonts`, `/logo` и маршрутизатор не поддерживают публикацию в подпапку.

## Структура
`src/pages/` — страницы · `src/components/{layout,blocks,gallery,ui}/` — компоненты · `src/lib/` — маршрутизатор, SEO, расписание · `src/data/` — контент · `src/styles/` — стили · `public/` — изображения, логотипы, шрифты · `scripts/prerender.mjs` — пререндер.
